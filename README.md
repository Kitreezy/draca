# Draca — «наведи и забери»

Прототип: наводишь камеру iPhone на экран Mac, держишь палец — на Mac появляется прицел.
Отпускаешь — iPhone получает то, что под прицелом: файл (Finder), ссылку (браузер) или снимок окна.

## Как это работает

1. Пока палец на экране iPhone, Mac показывает по краям 8 QR-маркеров; в каждом зашиты его координаты.
2. iPhone находит маркеры (`Vision`), строит гомографию «кадр → экран» и переводит центр прицела в точку на экране Mac.
3. Точка улетает на Mac по `MultipeerConnectivity`, Mac рисует прицел.
4. На отпускании Mac через Accessibility ищет файл/ссылку под точкой, иначе снимает окно (`ScreenCaptureKit`) и шлёт файл.

## Запуск

```bash
xcodegen generate
open Draca.xcodeproj
```

- **DracaMac** — запусти на Mac. Иконка прицела в строке меню. При первом снимке macOS попросит доступ к записи экрана;
  для файлов и ссылок под прицелом — пункт меню «Разрешить доступ…» (Accessibility).
- **DracaPhone** — только на реальном iPhone (в симуляторе нет камеры). Укажи свою команду в Signing & Capabilities.
- Оба устройства — с включёнными Wi-Fi и Bluetooth, рядом друг с другом.

Подключение в прототипе без спаривания — любой iPhone с приложением рядом может подключиться.
